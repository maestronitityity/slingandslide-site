# Sling & Slide website

Public site for the Sling & Slide game, served by GitHub Pages:

- `index.html`: home page (App Store marketing URL)
- `privacy.html`: privacy policy (App Store / TestFlight privacy policy URL)
- `support.html`: support page (App Store support URL)

Plain HTML and CSS, with no build step. The game's code lives in a separate private repo.
